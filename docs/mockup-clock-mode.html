MOCKUP · 供讨论，非最终实现仅时间形态交互重设计

设计原则：「聚焦」是一个双向开关，不是一个单向陷阱。进入方式和退出方式一一对应、可见可发现；窗口拖拽只发生在边缘留白和把手区，中央时间区域保留完整鼠标交互。

变更 ①控制条新增 「◎ 聚焦」按钮（替代现在的 ◉，位置固定在 ADB 左侧，与其它按钮同排）。双击星球是第二入口——星球是页面最大的视觉主体，双击它进入"只看时间"符合直觉（类比视频播放器双击全屏）。

三、钟面态 → 悬停浮现退出药丸（不再是无出口的陷阱）

👆 把鼠标移到下面钟面上试试
01:22:33.645
⠿ 拖动◈ 置顶✕ 还原窗口
首次进入 3 秒提示：双击退出 · 悬停右上角 · 右键更多 · 拖边缘移动（之后不再显示）

变更 ②悬停浮现药丸（视频播放器控制条模式）：静止时纯显示，鼠标移入右上角浮现「⠿ 拖动 / ◈ 置顶 / ✕ 还原窗口」。
变更 ③双击钟面 = 退出——为此把拖拽区从"整个面板"改为边缘留白 + ⠿ 把手，中央时间区域恢复完整鼠标事件（这是现在双击失效的根因）。
变更 ④首次进入显示 3 秒操作提示，之后记住不再打扰。

五、相对现状的变更清单

  • ① 入口对称：进入靠 ◉/Ctrl+1，退出靠隐形手势 进入=右上「◎ 聚焦」或双击星球；退出=悬停药丸 / 双击钟面 / 右键 / Esc——每个状态都有至少两个可见或半可见出口
  • ② 拖拽区拆分：整个面板 = 拖拽区（吃掉一切点击） 拖拽只保留边缘 8px 留白 + ⠿ 把手，中央时间区双击可用
  • ③ 首次引导：无提示，用户困在钟面 首次进入浮现 3 秒操作提示（tc.hint.clock 持久化）
  • ④ 形态收敛：正常/宽屏/窄屏/手机屏/小窗/仅时间/全屏 正常 / 小窗 / 仅时间 / 全屏 四档（已完成），宽屏等删除
  • ⑤ 字号等比：钟面字号 12.6vw 随窗口拉伸等比缩放（已完成，保留）
  • ⑥ C 键简化：五档循环 正常 ⇄ 小窗 二态切换（已完成，保留）

六、待你拍板的问题

  • Q1 钟面态要不要保留「穿透」？目前悬停药丸里没放（穿透开启后药丸也点不到，需要从完整态入口管理）。方案 A：砍掉穿透；方案 B：放右键菜单「穿透 开/关」
  • Q2 双击星球进入聚焦——星球同时是击拍热区（左键击拍），双击会先触发两次击拍判定。可接受 / 或只保留按钮入口？
  • Q3 钟面态默认尺寸 280×96 保持，还是加一档「大钟面」（如 560×120，适合直播/演示）？
