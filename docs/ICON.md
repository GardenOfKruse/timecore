# 应用图标生成规范（给 Codex / 任意生成工具的提示词）

## 目标文件

- 输出保存为：`build/icon-source.png`
- 尺寸：**256×256**（正方形，必须严格等比）
- 背景：**透明**（或深空底色圆角方形，二选一）
- 格式：PNG（RGBA）

> 放好后运行 `node scripts/make-icon.mjs`，会自动把这张 PNG 封装成 `build/icon.ico`。

## 风格描述（直接复制给生成工具）

深空科技风的桌面应用图标，表现一颗悬浮的发光星球被轨道环绕：

- 底色：极深的导航蓝径向渐变（中心 #0d1b33 → 边缘 #05080f），整体占圆形画布约 88%
- 主体：中央一颗程序化风格的小星球（直径约画布 45%），蓝绿海洋（#1a6e9e → #40c4e0），薄荷绿大陆斑块（#5aa878），少量白云纹理，星球边缘有一圈柔和的青色大气辉光（#39d7ff，向外渐隐）
- 环绕：两条银白色细椭圆轨道（#cfe4f2，宽 2px，倾角约 -25° 和 18°）斜穿星球前后，其中一条轨道上有一颗 6px 的亮青色卫星圆点（#8ef7ff，带辉光）
- 点缀：星球右上方 2~3 个微小的十字星芒（#8ef7ff，透明度 60%）
- 线条：玻璃质感——所有元素带 1px 亮边（rgba(200,235,255,0.35)）与轻微外发光
- 构图：中心对称、元素克制，外圈留白 10%，不出现任何文字
- 风格关键词：扁平微拟物、深空导航、精确仪器感、辉光而不发光过度

## 反例（避免）

- 纯黑剪影、低对比深蓝叠深蓝
- 拟真照片质感、复杂渐变噪点
- 文字、时钟表盘、过于复杂的场景

## 多尺寸说明

Windows 安装包只需 `icon.ico` 内含 ≥256×256 一档即可。若生成工具支持多尺寸导出（16/32/48/256），可一并给出，但目前单张 256×256 PNG 已满足打包要求。
